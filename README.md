# 双卷印发校核

本地双卷（A/B）试卷印发与校核工具：Python Flask + SQLite 后端，原生 JavaScript 前端。

## 功能

- **题库**：录入单选题（题干 + 四个选项 + 正确选项），每题、每个选项都有稳定标识（如 `Q-…`、`O-…`）。
- **编排**：分别调整 A、B 两卷的题序与选项顺序，卷面字母按调整后顺序生成。
- **封存**：两卷从同一题库修订一次性封存，各自生成可打印的**试卷、答题卡、答案表**；答题卡的题号与选项字母与对应卷面一致（同源生成）。
- **隔离**：封存后编辑题库不改变已印卷面与答题卡（封存卷保存内容快照）。
- **勘误**：按封存题目与当时印出的选项提交；校验通过则同时更新两卷答案表，记录各卷题号及勘误前后的选项字母并永久保留。选项不属于封存题目、或任一卷缺少映射时，**整次拒绝，原答案不变**。
- **回看**：封存卷内容与历次勘误均可在网页查看。

## 启动（Docker，单条命令）

```bash
docker compose up --build
```

然后打开 **http://localhost:8000**。

## 本地运行（无 Docker）

```bash
pip install -r requirements.txt
python app.py
```

同样访问 http://localhost:8000 （可用环境变量 `PORT` 修改端口）。

## 使用流程

1. **题库**：新增/编辑题目，指定正确选项。
2. **编排**：用 ↑↓ 分别调整 A、B 卷题序与每题选项顺序（自动保存），点击「封存 A、B 卷」。
3. **封存卷**：查看某批封存内容，打印两卷的试卷 / 答题卡 / 答案表。
4. **勘误**：选择批次与封存题目，勾选更正后的选项提交；页面下方可回看历次勘误。

## 数据

- SQLite 文件默认在 `./data/exam.db`；容器内为 `/app/data/exam.db`（Compose 挂载命名卷 `exam_data` 持久化）。
- 可用环境变量 `DB_PATH` 覆盖数据库路径。

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/api/questions` | 题库列表 / 新增题目 |
| PUT/DELETE | `/api/questions/<qid>` | 修改 / 删除题目（不影响已封存卷） |
| GET | `/api/arrangement` | 两卷编排草稿 |
| PUT | `/api/arrangement/<A\|B>` | 保存某卷题序与选项顺序 |
| POST | `/api/seal` | 同一题库修订封存 A、B 两卷 |
| GET | `/api/batches`、`/api/batches/<id>` | 封存批次列表 / 详情 |
| POST | `/api/errata` | 提交勘误（整次校验，全过或全拒） |
| GET | `/api/errata` | 历次勘误 |
